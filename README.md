# IPcoll — Instagram Post Collector

IPcoll is a small learning and portfolio project for building a personal searchable archive of useful public Instagram image posts.

The project is intentionally developed in small, verifiable stages without unnecessary infrastructure.

## Current Status

**Stage: project cleanup and foundation.**

Implementation has not started yet.

## MVP Idea

A public Instagram image-post URL is collected through Telegram, processed by scheduled automation, archived on FTP storage, and exposed through a simple mobile-friendly static catalog.

See [`docs/PROJECT.md`](docs/PROJECT.md) for the project definition and MVP boundaries.
